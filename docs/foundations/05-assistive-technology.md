# Assistive technology

## What is assistive technology?

**Assistive technology (AT)** is any product, piece of equipment, or system that makes learning, working, and everyday life easier for people with disabilities. Some assistive technologies are hardware, such as special keyboards. Many others are already built into phones and computers as settings and apps.

When you design websites and apps, you need to know which assistive technologies people may use to access them. **Good UX designers keep assistive technology in mind during the whole design process**: when they research users, when they define needs, when they design, and when they test.

## Common types of assistive technology

### Color modification

**Color modification** features change the colors on the screen to make content easier to see, for example **high-contrast mode** and **dark mode**.

*How to design for it:* make sure your design is readable in both light and dark themes, and never use color as the only way to communicate something. For example, an error message should include an icon or text, not only red color.

*Example:* a designer creating an online form for a sports club learns that some members switch between light and dark mode depending on the time of day. The designer adds a light/dark toggle and checks that all labels, input fields, and buttons stay clearly visible in both modes.

### Voice control

**Voice control** lets people navigate and operate a device using only their voice, without touching the screen, mouse, or keyboard. A related technology, **speech to text**, lets users write text by speaking.

*How to design for it:* give every button and link a clear, visible label, so users can say "Tap Continue" and the system knows exactly what they mean.

*Example:* a designer working on a smart lamp creates a **voice user interface (VUI)**, so users can say "Turn the light to 50 percent" instead of using an app.

### Switch devices

A **switch device** replaces the need for a keyboard or a mouse. It can be a large button, a sip-and-puff tube, or a head-movement sensor. **Keyboard navigation**, where users move through a page using only the Tab, Enter, and arrow keys, is the most common related technique.

*How to design for it:* make sure every interactive element can be reached and used with a keyboard, in a logical order, and that the focused element is clearly highlighted.

*Example:* during testing of a cinema booking website, one participant can't use a mouse. The team checks the prototype and makes sure the whole booking flow, including seat selection, works with the keyboard alone.

### Screen readers

A **screen reader** is software that reads aloud everything on the screen: text, buttons, links, and descriptions of images. Screen readers are especially important for blind people and people with low vision.

Screen readers rely on **alternative text (alt text)**, a short written description of a non-text element, such as an image or a chart. Alt text also appears when an image fails to load, for example on a slow connection.

*How to design for it:* decide which images carry meaning and which are only decorative. Write short, clear alt text for the meaningful ones. For example, "Bar chart showing sales doubling between January and March" is much more helpful than "chart.png".

## Learn more

These free resources are good next steps if you want to explore accessibility further:

- **[Designing for Global Accessibility](https://design.google/library/designing-global-accessibility-part-1/)** - a three-part article series from Google's design team about awareness, context, and inclusive defaults.
- **[Material Design accessibility guidelines](https://m3.material.io/foundations/accessible-design/overview)** - practical guidance on designing accessible interfaces.
- **[Web Content Accessibility Guidelines (WCAG) overview](https://www.w3.org/WAI/standards-guidelines/wcag/)** - the international standard for web accessibility.

::: tip Key takeaway
Assistive technologies such as color modification, voice control, switch devices, and screen readers help people with disabilities use digital products. Design with them in mind from the very beginning, not as a last-minute fix.
:::
